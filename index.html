Under the hood
Three ideas, one decision.

      
Each course topic has a distinct job. Search finds where we can go, Bayes estimates what we will find there, and the MDP decides what to do about it.

    

    

      

        01 · Week 2 · Uninformed search
        
Find the shortest path

        
ARAruana · search & routes

        
Breadth-first search expands the grid layer by layer using a FIFO queue and a predecessor map. Because every move costs one step, the first time it reaches a space it has found a shortest route. Obstacles and spaces that are likely occupied are never entered.

        
queue ← [start]; while queue: cell ← pop_front()

        Open the search lab →
      

      

        02 · Week 6 · Bayesian inference
        
Update the odds

        
MAMadina · probability

        
A sensor is right 90% of the time when a space is taken, but also raises a false alarm 20% of the time. Bayes' rule combines this with a 40% prior: one alert lifts the estimate to 75%; a quiet sensor drops it to 7.7%.

        
P(occ | alert) = 0.9·0.4 / (0.9·0.4 + 0.2·0.6) = 0.75

        Open the Bayes lab →
      

      

        03 · Week 5 · MDP & Value Iteration
        
Make the call

        
ALAlnur · planning & tests

        
A finite belief-state MDP weighs four actions — Drive, Check again, Skip, Exit — using rewards, a discount factor and Bayes-derived transitions. Bellman sweeps repeat until values stop changing, giving the best action for every belief.

        
V(s) ← maxa [ R(s,a) + γ Σ P(s′|s,a) V(s′) ]

    A note on the model
    Simple by design.
    Honest about limits.
    
    
    
      
    This is a classroom-sized simulation, not a live parking service. The map, sensor readings and rewards are teaching assumptions chosen to show how a system can decide under uncertainty.
    
      
      
        
    • Sensor sensitivity 0.90 and false-alarm rate 0.20 are assumptions, not measured values.
      • 
        
    • Repeated readings are conditionally independent given the true occupancy.
      • 
        
    • Beliefs are rounded to 1% for planning; each space allows one recheck.
      • 
        
    • Spaces are considered in a fixed order (nearest to the entrance first); distances are measured from the entrance.
      • 
        
    • This is model-based planning — not Q-learning and not an exact continuous-belief POMDP solver.
      • 
        
    • Spaces at or above 50% occupancy are never used as a destination or driven through.
