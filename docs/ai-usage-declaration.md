# AI Usage Declaration

**Project:** Mini Smart Parking Guide  
**Course:** AI Fundamentals  
**Team:** Dilnaz, Aruana, Madina and Alnur

The Mini Smart Parking Guide was developed by the student team with substantial assistance from AI tools. ChatGPT and Anthropic Claude Opus 5.5 were used at different stages of implementation, debugging, testing and preparation of written and presentation materials. This assistance was more than spelling correction or minor formatting and is disclosed so the submitted work can be assessed transparently.

## ChatGPT assistance

ChatGPT assisted in earlier project stages with transferring the initial notebook-based work into a browser application; implementing and revising JavaScript logic; generating, running and improving automated tests; debugging routing and application behaviour; and drafting or refining the technical report, presentation, demonstration materials and defense guidance. The team reviewed suggestions and generated text and made the final decisions about what was retained.

## Team responsibility and limitations

The students set the project context and course objectives, reviewed the application and AI-generated suggestions, selected the material retained in the submission, and remain responsible for checking calculations, verifying outputs, understanding assumptions and explaining the work individually. The Team Contribution Statement identifies each member’s primary review and defense topic; it is not a claim that every listed code component was independently written by that student.

The project uses a simulated parking lot and teaching assumptions for sensor sensitivity and false-positive rate. It does not claim model training, live sensor measurements, an original field study or real-world deployment performance. Each member should confirm this declaration and add a real signature and date only after review.
